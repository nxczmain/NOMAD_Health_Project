NETIN 3.0 for Windows x64

Open NETIN.exe from this folder. Keep the interface and WebView2 DLLs beside it.
Microsoft Edge WebView2 Runtime and .NET Framework 4.8 are required.
For AI responses, run Ollama locally with qwen3:4b, or start the existing
portable installation through Abrir-NETIN.cmd.

Choose an astronaut and a mission stage. Follow the daily photo, check-in,
motor test and journal. Documents loads the mission library from Markdown.
