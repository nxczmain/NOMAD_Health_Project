NOMAD for Windows x64

Open NETIN.exe from this folder to start NOMAD. Keep the interface and WebView2 DLLs beside it.
Microsoft Edge WebView2 Runtime and .NET Framework 4.8 are required.
For AI responses, install and open Ollama for Windows.
In Settings, check the connection and download the required models if missing.
Use Test and use model under Medical model to verify MedGemma.
MedGemma handles medical interpretation and synthetic ultrasound.
The Ultrasound Samples folder includes synthetic training images.

See INSTALLATION.md for the complete judges' walkthrough. The Windows ZIP
includes the indexed research library, available in Documents.

Choose an astronaut and a mission stage. Follow the daily photo, check-in,
motor test and journal. Documents loads the mission library from Markdown.
