## Reading the files

Each document uses a consistent title, source link, section headings, paragraphs, lists, and tables. Longer documents include a contents list when suitable. Technical source metadata is placed at the end.

The original extracted wording, numerical values, and source links are retained. Formatting does not correct errors or recover figures, scanned text, or complex layouts from the PDF. Refer to the original for those elements.

## Files and provenance

- 503 Markdown documents; repeated source PDFs are retained.
- 431 unique original PDF byte contents and 72 additional identical copies.
- `conversion_manifest.json` maps source PDFs to files.
