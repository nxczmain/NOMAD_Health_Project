# App screen guide

Explore NOMAD’s Windows v3.2.3 interface using a synthetic Earth Orbit demo profile. Each screenshot illustrates a screen or an important workflow. Select a screenshot to inspect it at full size.

[Getting started](#getting-started) · [Assistant and daily workflow](#assistant-and-daily-workflow) · [Health and medical review](#health-and-medical-review) · [Exercise and records](#exercise-and-records) · [Medications and library](#medications-and-library) · [Settings and developer tools](#settings-and-developer-tools)

## Getting started

### Crew roster

Choose the mission stage, select a local crew profile and sign in. Select **Create profile** to register another crew member.

[![The welcome page with a mission-stage selector and two demo profiles](images/app/01-crew-roster.jpg)](images/app/01-crew-roster.jpg)

### Create profile

Enter a crew name and choose a **Role or rank**. Select **Continue** to set the local password.

[![Profile-creation dialog with name and role fields](images/app/02-create-profile.jpg)](images/app/02-create-profile.jpg)

### Home

Start a **Daily photo**, **Daily check-in**, **Motor test** or **Journal** entry. The latest indicators show what the profile has recorded. **Change stage** switches the mission context.

[![The Home dashboard with crew identity, the daily routine and latest measurements](images/app/03-home.jpg)](images/app/03-home.jpg)

### Daily photo

Frame the image, select **Take photo** and review the preview before saving. You can continue without a photo when the daily routine prompts you. The guide image uses a simulated camera preview.

[![Daily photo screen with a labeled simulated camera preview and a framing guide](images/app/22-daily-photo.jpg)](images/app/22-daily-photo.jpg)

## Assistant and daily workflow

### Chat with Ham

Ask Ham a question in **Message** and select **Send**. Open **Sources** when a reply cites documents. Use **Auto-read**, **Listen** and **Stop audio** to control speech.

[![Assistant chat with an example question about reviewing a past check-in](images/app/04-ham-chat.jpg)](images/app/04-ham-chat.jpg)

### Guided daily check-in

Answer the immediate-help question and follow the prompts. When a pain scale appears, select an intensity and choose **Save pain rating**. Use **Save and finish** to save the observations already collected.

[![A symptom follow-up with a pain-intensity slider and a save control](images/app/05-daily-check-in.jpg)](images/app/05-daily-check-in.jpg)

### Check-in workspace

Review today’s check-in and continue to routine items such as the motor test, journal or daily photo. The **Daily check-in** tab in Assistant is where you start the guided conversation.

[![The daily check-in review workspace with status and links to the routine](images/app/06-check-in-workspace.jpg)](images/app/06-check-in-workspace.jpg)

### Motor skill activities

Open **Motor test** from the daily routine. Choose an activity and the hand you will use, then start a test or practice round. Compare repeated results under similar test conditions.

[![Motor skills activities with a game selector, instructions and hand choice](images/app/12-motor-skill-activities.jpg)](images/app/12-motor-skill-activities.jpg)

### Journal

Add notes about your day. NOMAD saves the entry as you write. Open **Records** to find the saved entry by date.

[![Daily Journal screen with a writing field and status](images/app/13-journal.jpg)](images/app/13-journal.jpg)

## Health and medical review

### Health overview

Use **Health → General** to see recent observations and measurements. Choose a measurement and period to review its trend or select **Prepare medical review** to assemble a handoff.

[![General Health tab with check-in summary and latest measurements](images/app/07-health-general.jpg)](images/app/07-health-general.jpg)

### Body map

Use **Health → Physical → Body map** to select a region, record a symptom and set its intensity. Concerns logged during a check-in also appear here.

[![Physical Health tab with body region illustration and symptom form](images/app/08-body-map.jpg)](images/app/08-body-map.jpg)

### Ultrasound simulation

Choose **Ultrasound simulation** under **Physical**. Select a synthetic image from the Windows download’s **Ultrasound Samples** folder for a model-backed demonstration.

[![Physical Health tab showing the simulated ultrasound upload and analysis panels](images/app/09-ultrasound.jpg)](images/app/09-ultrasound.jpg)

### Mental health

Choose a mood, add any context and select **Save mood check-in**. The screen also shows recent mood entries for the profile.

[![Mental Health tab with mood choices and optional note fields](images/app/10-mental-health.jpg)](images/app/10-mental-health.jpg)

### Motor skill results

Open **Health → Motor Skills** to view recorded activity and select an activity for details. The view compares results for the signed-in profile and mission stage.

[![Motor Skills health tab with a breakdown of recorded activities](images/app/11-motor-skill-results.jpg)](images/app/11-motor-skill-results.jpg)

### Medical review

In **Health → General**, choose **Prepare medical review**. Review the draft handoff with observations, recent check-ins, medications and any sources. **Save medical review** exports a copy for the crew medical officer.

[![A medical review dialog containing a demo crew summary and check-in observations](images/app/26-medical-review.jpg)](images/app/26-medical-review.jpg)

## Exercise and records

### Exercise

Use **Today’s routine** to review the schedule for the selected stage. Log the activity and minutes completed. Enter exercise energy from the equipment if available, or use **Energy intake** to log food energy separately.

[![Exercise screen with a daily plan and completed-session form](images/app/14-exercise.jpg)](images/app/14-exercise.jpg)

### Exercise demonstrations

Scroll down in **Exercise** to see the five movement demonstrations. **Pause animations** stops them. **Exercise research in Documents** opens the source collection.

[![Five looping exercise cards and playback controls](images/app/15-exercise-demonstrations.jpg)](images/app/15-exercise-demonstrations.jpg)

### Records

Choose a date and mission stage to find check-ins, measurements, conversations and journal entries. Use **Save daily report** to export that day’s record.

[![Records screen with a date filter, stage filter and a daily record](images/app/16-records.jpg)](images/app/16-records.jpg)

### Reports and trends

Choose **Reports and trends** from Records. Use **7 days** or **30 days** to select the period and review its readings and routine activity. For measurement charts, open **Health → General**.

[![Weekly log showing a date range, summary and measurement table](images/app/17-reports-and-trends.jpg)](images/app/17-reports-and-trends.jpg)

## Medications and library

### Medication history

Review doses already logged for the current stage. Use **Record medication taken** to add an entry or **View inventory** to check documented supplies.

[![Medication history for the selected stage with a record button and inventory shortcut](images/app/18-medications.jpg)](images/app/18-medications.jpg)

### Record medication taken

Enter the medication, the amount actually taken and the time. Add inventory use or an estimated effect interval only when that information is available.

[![Dose entry dialog with medication, amount, time and optional inventory fields](images/app/27-record-medication.jpg)](images/app/27-record-medication.jpg)

### Medical supplies

Open **Medical Supplies** in Health or **View inventory** in Medications. Search the historical catalog and edit stock after verifying the amount on board. The catalog comes from the [2015 ISS kit reference](../references/README.md#start-with-these-references).

[![Medical Supplies inventory dialog over the demo Home screen](images/app/21-medical-supplies.jpg)](images/app/21-medical-supplies.jpg)

### Documents

Search the bundled references, choose **Exercise research** to filter them or use **Load Markdown folder** to import a collection. Open a result in the reading pane.

[![Documents page with the Local library search and reading pane](images/app/19-documents.jpg)](images/app/19-documents.jpg)

### Document reader

Enter a **PDF page** number and select **Go**, use the previous and next controls or select a shortcut such as **ACLS algorithm**, **CPR** or **Fractures**. Use **Open original PDF** when a bundled original is available. The historical ISS manual’s ACLS algorithm starts on PDF page 117 and its CPR section starts on page 145. [Sources](../references/README.md#start-with-these-references)

[![Historical ISS checklist in the reader at PDF page 117](images/app/20-document-reader.jpg)](images/app/20-document-reader.jpg)

## Settings and developer tools

### Settings

Change the theme, text size, Ham animation and audio levels. Open **Edit profile** to update profile details or **Sign out** to return to the crew roster.

[![Settings screen with appearance, audio, profile and assistant cards](images/app/23-settings.jpg)](images/app/23-settings.jpg)

### Profile settings

Edit your name, **Role or rank**, medical contact, history or allergies. Choose **Developer** and save to make issue reporting available to this profile.

[![Edit profile dialog with crew role and medical contact fields](images/app/24-profile-settings.jpg)](images/app/24-profile-settings.jpg)

### Local assistant setup

In **Settings → Local assistant**, select **Check connection** to check Ollama. Download required models when prompted and use **Test and use model** under **Medical model** to verify MedGemma. [Installation and troubleshooting](INSTALLATION.md)

[![Settings cards for the local Ollama connection and MedGemma model test](images/app/28-local-assistant-setup.jpg)](images/app/28-local-assistant-setup.jpg)

### Developer issue report

Use **Report issue** from a Developer profile while the issue is visible. Review the automatically captured image, enter a category, title and description, then select **Save report**. Use **Settings → Developer tools → Open reports folder** to find the local **NOMAD-Developer-Reports.html** file. Review the screenshots before sharing it.

[![Developer report popup showing a captured app screenshot and report fields](images/app/25-developer-report.jpg)](images/app/25-developer-report.jpg)
