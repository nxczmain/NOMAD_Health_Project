The [source catalog](SOURCES.md) lists every indexed document and every repository PDF, including the ISS medical checklist and its CPR references. It links the Markdown, original PDF and recorded publisher URL or collection copy where available.

## Use the documents in NETIN

In NETIN, open **Documents** to browse the indexed library bundled with the Windows ZIP. Select **Exercise research** to open its Markdown references and linked PDFs. The repository also contains the original PDFs for checking tables, figures and layout. Use **Load Markdown folder** to import custom references.

## File correspondence and integrity

The [original import manifest](../Investigation%20%28.md%29/conversion_manifest.json) records 510 PDF files and 503 PDF-to-Markdown correspondences. Of seven entries initially listed without Markdown, six match an already converted file by SHA-256. The current library includes the medical kit conversion. NIMH entries contain attributed text and links to the publications. The ERC 2025 reference summarizes its microgravity section and links to the original page.

Two source folders contain repeated PDF filenames. Both copies are retained; one copy in each pair has a ` (2)` filename suffix. The manifest records their original names and source IDs.

The imported Markdown README describes the conversion performed before this import. This change imports the available files without changing their contents or recreating the conversion.
